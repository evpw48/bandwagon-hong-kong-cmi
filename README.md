## 搬瓦工香港 CMI 是条什么线路？去程回程路由拆解

搬瓦工香港 CMI 对应的是香港 HK85 机房，底层设施来自 xTom，部署在 Equinix 香港数据中心。搬瓦工的香港产品线只有两条，容易搞混：一条是走电信 CN2 GIA 的香港常规套餐（月付 $89.99 起的高端线），另一条就是今天的主角 HK85，走移动 CMI 线路，价格低一个档位。

回程方向，三网（电信、联通、移动）都从移动 CMI 骨干网直连回国内，这个状态从 2023 年 4 月恢复之后一直保持。去程方向有差异：移动全程 CMI 直连；电信走 CN2 GIA 直连；联通走 AS4837 直连。电信和联通的去程早年是绕日本 NTT，之后才陆续升级成直连。

这个结构决定了使用体验的大方向。移动用户等于全程在自己家骨干网上跑，加上香港离大陆的物理距离优势，10~30ms 的延迟放在全球 VPS 里都是第一梯队。电信和联通用户回程走 CMI 属于跨网传输，能用、也稳定，但体验通常比移动用户低半档——同一条线路，不同宽带的表现差距会很明显。所以买之前建议用测试 IP 45.78.18.149 在本地 ping 和 traceroute 一遍，你自己的宽带是什么表现，比看任何评测都直接。

## 路由稳定性：2023 年那次 NTT 回程事故说明了什么

CMI 这条路由的质量有一个前提要先讲清楚：它由上游 xTom 与移动的合作状态决定，搬瓦工自己不完全可控。2023 年 2 月出过一次事——xTom 调整了香港 CMI 机房的路由，电信和联通的回程被切到 NTT，延迟和丢包肉眼可见地恶化。当时的测试数据里，广州电信回程延迟一度超过 280ms，上海电信接近 300ms；而正常走 CMI 回程时，三网延迟都在几十毫秒的量级。这次异常持续了一个多月，2023 年 4 月恢复三网 CMI 回程，之后去程也从 NTT 升级为直连。
